线B论文 · 统计方法说明（求背书精简版）

用途：转给统计背景合作者/顾问审阅，请其确认方法表述无误、可对方法部分背书。 对应论文：《阴道菌群组成对细菌性阴道病治疗后菌群学康复的预测价值：跨三个独立队列的评估》（拟投 JCM）。 说明：本文为阴性结论（治疗前 16S 菌群对"菌群学康复"的预测价值有限），方法均为此结论服务。

一、研究设计概要

  • 结局：随访时点乳杆菌相对丰度 ≥50%（菌群学康复），属替代结局（非临床硬结局）。
  • 队列：三个独立 16S 队列（Xiao 2016 / Mollin 2022 / Gustin 2022），另含 Plummer 2023 作为结局偏斜的边界情形。发现/验证结构：Xiao 训练、Mollin/Gustin 外推。
  • 主分析：LASSO 逻辑回归预测菌群学康复，AUC 评估 + 内部交叉验证 + 独立外部队列验证。

二、需审阅确认的 7 个方法点

1. 特征预处理：log1p 变换 + StandardScaler + 出现率 ≥5% 过滤

  • 菌群相对丰度右偏严重，采用 log(1+x) 压缩跨度；LASSO 对特征尺度敏感，故标准化；出现率 <5% 的稀有特征删除以减少噪声。
  • 请确认：该预处理组合对高维稀疏菌群数据是否标准、有无更优替代。

2. LASSO 逻辑回归主模型（★最高优先）

  • 特征为数百个菌属，样本仅数十例（n=33–54），普通回归易过拟合；LASSO 的 L1 正则将无关特征系数压至 0，兼作特征选择与防过拟合。
  • λ 经交叉验证选取（默认最小误差准则）。
  • 敏感性分析：随机森林 / XGBoost 结论一致（见补充材料）。
  • 请确认：① λ 选取准则（最小误差 vs 1-SE）哪个更稳妥；② 小样本（n≈50）下 LASSO 适用性及是否需要更保守的替代（如弹性网、ridge）。

3. 验证技术：无泄漏 / 20 随机种子 / bootstrap CI 口径

  • 无泄漏：预处理与标准化参数仅在训练集拟合。
  • 20 种子：重复划分训练/测试以检验稳定性。
  • bootstrap CI 条件于训练队列：外推时的 95%CI 反映测试集抽样变异，跨队列外推不确定性另由独立队列实测。
  • 请确认：该验证框架对小样本是否充分。

4. Plummer 队列结局偏斜 → LASSO 退化为空模型

  • Plummer 队列结局严重偏斜（康复率 91%），LASSO 学不到信号、退化为无特征被选中的空模型。
  • 处理：该队列不纳入建模主证据，仅作"结局偏斜边界情形"说明。
  • 请确认：此处理是否得当，有无必要用其他技术（如 Firth 校正、加权）补救。

5. richness 稳健性：rarefaction + 置换检验 + leave-one-out

  • rarefaction 抽平测序深度（排除"测得越多检出种越多"的技术假象）；
  • 置换检验 1000 次（检验真实关联是否显著强于随机打乱）；
  • LOO（33/33 无单样本驱动）。
  • 请确认：三项稳健性检验是否足以支撑"Gustin richness 信号真实"的判断。

6. 功效分析：最小可检测 AUC（0.711 / 0.869 / 0.778）

  • 给定样本量与结局比例，反推最小可检出效应，用于区分"真无信号 vs 样本不足"。
  • Xiao（n=54）：最小可检测 AUC 0.711，观测 ≈0.5 → 阴性为真无信号；
  • Plummer（结局 91% 偏斜）：0.869，几乎检不出中等效应；
  • Gustin（n=33）：0.778，其 richness 信号 0.776 恰在检出线上。
  • 请确认：三个数字的算法与解读是否准确（这是负结果论文的关键辩护）。

7. 连续结局剂量-反应（Spearman ρ）

  • 二元结局（康复 ≥50%）之外，以"随访乳杆菌丰度"与"Δ 乳杆菌丰度"作连续结局，检验 richness 的相关方向。
  • 结果：Gustin 队列 ρ=−0.565 / −0.557（负相关，单调剂量-反应），Xiao/Plummer 方向相反。
  • 请确认：该补充分析口径是否合理、结论（队列特异性）表述是否得当。

三、已简化处理（不再需要逐项解释）

  • 多重校正：双重校正（Bonferroni + BH-FDR）已简化为单一 BH-FDR。
  • 队列异质性：交互项似然比已简化为三队列方向对比。
  • 术语："赢家诅咒"已改白话表述。

四、请重点回复的问题（summary）

  1. 卡 2（最高优先）：小样本下 LASSO-LR 作为主模型的适用性，λ 选取准则建议；
  2. 卡 6：功效分析三数字（0.711/0.869/0.778）算法与解读是否准确；
  3. 其余 5 点（预处理/验证技术/偏斜处理/稳健性/连续结局）表述是否有误或需补充。

附：核心结论的一句话定位（供审阅者判断方法是否与结论匹配）

治疗前 16S 菌群对"菌群学康复"的预测能力有限：全人群中等信号（AUC≈0.6）主要源于"乳杆菌标签耦合"（康复定义本身含乳杆菌），去该成分后大幅衰减；聚焦治疗对象（基线 CST IV 亚组）后接近随机；richness 仅在单一队列显著、未跨队列复现。方法选择均服务于"阴性结论是否站得住"这一核心问题。
