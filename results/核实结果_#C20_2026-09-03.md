## 一、任务一（必做）：λ 嵌套重估核实——**已核实，嵌套结构属实，无需重跑**

**结构说明**：λ 的网格 C∈{0.01, 0.05, 0.1, 0.5, 1.0} 在 `GridSearchCV` 内经 5 折分层 CV 评估——**该 CV 只见传入的训练数据**（外推场景=训练队列全集；内部 CV 场景=外层训练折），选完 C 后在同一训练数据上 refit。测试折/测试队列在 λ 选择的任何环节都不出现。`StandardScaler` 位于 Pipeline 内，内层每折各自标准化，无标量泄漏。

**结论句（可直接回论文 2.4）**：已核实，嵌套结构属实——λ 在每次训练/测试划分内部、仅用训练侧数据经 5 折交叉验证重新估计，测试侧完全不参与 λ 选择；四条管线（主矩阵、LOCO、holdout、train_main）结构一致，无需改代码重跑。

## 二、任务② 模型族敏感性（elastic-net α=0.5 + ridge）

6 个代表 cell × 3 族（L1 为同脚本内对照重跑，与锚点一致 ±0.002）：

| cell | L1（主协议） | elastic-net | ridge(L2) |
|---|---|---|---|
| A1 Xiao 内部 CV | 0.624 ± 0.164 | **0.636** ± 0.145 | 0.627 ± 0.167 |
| A2 Xiao→Mollin | 0.526 | **0.607** | 0.545 |
| A3 Xiao→Gustin | 0.556 | **0.594** | 0.558 |
| B1 Xiao CST4 内部 | 0.535 | 0.547 | **0.589** |
| B2 Xiao→Mollin CST4 | 0.504 | 0.515 | 0.544 |
| B3 Xiao→Gustin CST4 | 0.512 | 0.514 | 0.530 |

- **B 系（CST4，临床治疗对象）三族全部 0.504-0.589 ≈ 0.5**——阴性结论在线性正则化族稳健。
- A 系 0.526-0.636，无任一族 >0.65；elastic-net 略高但仍在「弱信号」区间。
- **结论句**：将 L1 换为 elastic-net（α=0.5）或 ridge(L2) 后，CST4 亚组 AUC 0.504-0.589、全人群 0.526-0.636，均无预测力——阴性结论不依赖正则化族选择（回应「高相关菌属下 L1 是否合适」：结论在 L1/L2/混合范数下一致）。

## 三、任务③ CLR 变换敏感性（伪计数 1e-4，L1 主协议）

| cell | log1p（主协议） | CLR | Δ |
|---|---|---|---|
| A1 Xiao 内部 CV | 0.624 | **0.523** ± 0.118 | −0.101 |
| A2 Xiao→Mollin | 0.526 | 0.591 ± 0.061 | +0.065 |
| A3 Xiao→Gustin | 0.556 | 0.601 ± 0.049 | +0.045 |
| B1 Xiao CST4 内部 | 0.535 | 0.494 ± 0.138 | −0.041 |
| B2 Xiao→Mollin CST4 | 0.504 | 0.512 ± 0.008 | +0.008 |
| B3 Xiao→Gustin CST4 | 0.512 | **0.472** ± 0.024 | −0.040 |

- **B 系全部 0.472-0.512 ≈ 0.5**（B3 轻微反转 <0.5，与噪声带宽一致）。
- ⚠️ 诚实注明：A1（Xiao 全人群内部 CV）从 0.624 降至 0.523——全人群层的 0.63 有约 0.1 依赖 log1p 变换；但同变换下 A 系外推反而升至 0.59-0.60，方向不一致，说明 0.5-0.6 区间的波动即噪声带宽。
- **伪计数稳健性（追加，`results_c20_clr_pseudo.csv`）**：四档伪计数（1e-2/1e-3/1e-4/1e-6）下 A1 = 0.581/0.543/0.521/0.504（随伪计数减小单调降至 ≈0.5）；B1 = 0.512/0.493/0.497/0.483、B3 = 0.529/0.475/0.472/0.504、B2 = 0.275/0.435/0.513/0.517（1e-2 档 B2 大幅反转，系大伪计数压缩稀有属所致）——**B 系全部 ≤0.53、无一档达到可用预测力，CLR 无预测力结论不依赖伪计数选择**；A1 的单调下降与 B2 的档间波动本身即构成层信号对分析选择敏感的又一佐证。
- **结论句**：以 CLR（伪计数 0.01%）替代 log1p 后，CST4 亚组 AUC 0.472-0.512 保持 ≈ 随机，全人群 0.52-0.60——阴性结论对组成性数据处理方式稳健（且在 1e-2 至 1e-6 四档伪计数下均成立）；Xiao 全人群内部 CV 在 CLR 下降至 0.523（伪计数减小进一步降至 0.504），进一步削弱全人群层弱信号的稳定性（支持主叙事）。

## 五、任务⑤ 非抽平 richness + 测序深度协变量（Gustin CST4，n=33，11 例康复）

深度 = 基线样本 ASV 表行和（`PRJNA691964/asv_table.csv`）；richness = 非抽平 species_observed（与主分析同源）。

| 分析 | 结果 |
|---|---|
| ① 非抽平 richness–结局 Spearman | **ρ=−0.4537, p=0.0080**（逐位复现主分析） |
| ② log(depth)–richness | ρ=+0.336, p=0.056（深度与 richness 正相关，常规） |
| ③ log(depth)–结局 | ρ=−0.317, p=0.072（边际，不显著） |
| ④ **partial ρ(richness, 结局 \| log depth)** | **−0.3886, p=0.0254**（信号存活，衰减 ~14%） |
| ⑤ logistic 结局 ~ richness + log depth | richness β=−0.297 **p=0.040**（显著）；depth β=−0.428 p=0.328（不显著） |
| ⑥ 深度分层 | 低深度组 ρ=−0.7745 (p=0.0004, n=16)；高深度组 ρ=−0.0158 (p=0.952, n=17) |
| ⑦ richness×depth 交互（logistic） | Wald p=0.077（小样本渐近不可靠）；**置换检验（5000 次）p=0.0038 显著** |

**解读（诚实呈现，两面都要）**：
- **正面**：richness 信号经三类深度调整均存活——rarefy（−0.392, p=0.024，已有）、partial ρ 控制深度（−0.389, p=0.025）、logistic 多变量调整（p=0.040）。
- **⚠️ 负面（新增防御点）**：交互检验（置换 p=0.004）显示关联强度**依赖测序深度**——低深度组强（−0.77）、高深度组消失（−0.02）。不能排除部分信号来自深度与结局的边际负相关（ρ=−0.317）在低深度样本中的放大。**建议以局限呈现，勿写「完全不受深度影响」**；Gustin 2022 原文同样使用未抽平诊断样本 richness（directional replication 的边界一致）。

**结论句**：非抽平 richness 与治疗结局的负关联在控制测序深度后保持显著（partial ρ=−0.389, p=0.025；logistic 调整后 p=0.040），但交互检验提示该关联在低测序深度样本中更强（置换 p=0.004），作为局限如实报告——richness 信号对深度调整稳健，但不排除深度相关的估计不均匀性。
